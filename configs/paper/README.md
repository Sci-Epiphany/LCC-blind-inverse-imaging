# Recovered paper configurations

These YAML files are copied from the complete Hydra records used by the
reported runs:

- `gaussian.yaml`: linear Gaussian blur.
- `motion.yaml`: linear motion blur.
- `nonlinear.yaml`: BKSE KernelWizard nonlinear blur.

They contain task-specific learning rates, regularization weights, noise
scales, model choices, and data ranges. Paths to datasets and checkpoints must
be adjusted for the local environment.
